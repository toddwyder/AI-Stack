# Developer Skill Specification

## What
- Goal: satisfy the issue’s expected outcome.
- Output: code + completed evidence packet.

## How
- Read the authoritative GitHub issue and required artifacts.
- Read back the goal and output.
- Ask only essential questions not answerable from GitHub.
- Make a plan.
- If root cause is not demonstrated, use correlation tracing; add only the minimum diagnostics needed.
- Implement with TDD.
- Run required unit, integration, and E2E tests.
- Update the evidence packet as work occurs.
- Produce a reviewable candidate and hand off through GitHub.

## Stop
- Do not mock evidence or tests to manufacture a pass.
- Do not claim Pass without the minimum required evidence.

## Model
- Sonnet or Terra Medium
